# reach.postproc: flood forecast error post-processing

Transparent autoregressive and autoregressive moving-average
post-processing for flood forecasts. Provides characteristic-root
analysis, Environment Agency parameter assessment, fixed lead-time
evaluation, diagnostics, scoring, and presentation-ready plots.
