# Extract a TJ-AR projected series

Extract a TJ-AR projected series

## Usage

``` r
tj_ar_series(x)
```

## Arguments

- x:

  A result from
  [`forecast_tj_ar()`](https://jonpayneea.github.io/reach.postproc/reference/forecast_tj_ar.md).

## Value

A copied `data.table` of projected error by lead time.
