# Source style

The package source follows these rules:

- Four-space continuation indentation.
- One argument per line for multi-argument calls and definitions.
- One calculation per statement where the intermediate value carries meaning.
- Section comments organise source files.
- Inline comments explain mathematical indexing, conventions and numerical choices.
- Every exported class, generic and function has a roxygen2 block.
- Public tabular outputs use data.table.
- Calculation functions do not write files.
